# fog-landing

## Les agents FOG vivent ailleurs

Ce dépôt a servi de brouillon le 20 septembre 2026 pour des agents FOG Production.
C'était une erreur : le système d'agents de Chris existe déjà, dans
**[`chrisbombele/jarvis-starter-kit`](https://github.com/chrisbombele/jarvis-starter-kit)**,
avec un COO, cinq agents spécialisés et dix-neuf commandes.

Les agents créés ici ont été retirés pour ne pas maintenir deux systèmes en parallèle.
Sur les six, deux couvraient un vrai manque et ont été repris dans `jarvis-starter-kit` :

- **Agent CFO** : trésorerie réelle, prévisionnel, priorité de paiement, rentabilité
  par mariage, réserves, rémunération des propriétaires, patrimoine.
- **Agent Contrats** : contrats, clauses, reconnaissances de dette, escalade
  professionnelle.

Les quatre autres faisaient doublon avec le COO et les agents existants.
