# iPhone — modes de concentration

Page de configuration (à ouvrir sur le téléphone pendant le réglage) :
https://claude.ai/code/artifact/37762d5b-8434-4a57-87ad-b954fc5f0c66

Aucun outil externe ne peut configurer les modes de concentration, le Temps d'écran
ou les écrans d'accueil d'un iPhone — Apple ne les expose pas. C'est une config
manuelle, à taper une fois.

## Les modes, calqués sur les blocs du calendrier

| Mode | Horaire | Joignable par |
|---|---|---|
| 😴 Sommeil | 20h30 → 5h00, dim–ven | Conjointe, enfants + appels répétés |
| 🎯 Deep Work | 5h45–6h30 et 9h30–12h00, lun–ven | Conjointe + appels répétés |
| 👨‍👩‍👧‍👦 Famille | 6h30–7h30 et 17h00–20h30, lun–ven | Famille, école |
| 📞 Communication | 13h00–15h00, lun–ven | Tout le monde |

Gym, Repas et Operations n'ont pas de mode : un mode par bloc, c'est un système
abandonné en deux semaines.

Temps d'arrêt : 20h30 → 5h45 (la lecture de 5h05 tombe dedans).

## Règle pour l'agent

Les horaires des modes doublent ceux du calendrier. **Si un bloc est déplacé dans
Google Calendar, le signaler** : l'horaire du mode correspondant doit être déplacé
à la main sur le téléphone, sinon il se déclenche au mauvais moment. C'est le seul
endroit du système où la synchronisation n'est pas automatique.
