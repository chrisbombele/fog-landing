# Programme type — semaine

> Le Life OS Agent construit chaque brief du matin à partir de ce squelette.
> Ce n'est pas une prison : c'est la forme par défaut de la journée quand rien
> d'exceptionnel n'arrive. L'agent l'adapte aux vrais événements du calendrier.

## Version principale (gym à l'extérieur)

| Heure | Bloc | Contenu |
|---|---|---|
| 5h00 | Réveil | Eau + hygiène. Zéro téléphone. |
| 5h05–5h45 | **Spirituel** | Bible. |
| 5h45–6h30 | **Deep Work #1** | Le MUST DO #1, décidé la veille à la review du soir. |
| 6h30–7h30 | **Famille** | Enfants : lever, déjeuner, préparation, bus à 7h30. Téléphone rangé. |
| 7h30–7h45 | Buffer | Transition + collation. |
| 7h45–9h15 | **Gym** | Trajet + séance + douche. |
| 9h15–9h30 | Buffer | |
| 9h30–12h00 | **Deep Work #2** | Editing / création. Pas d'email, pas d'Instagram. |
| 12h00–13h00 | **Repas** | Sans écran. |
| 13h00–15h00 | **Communication** | Calls, DMs, emails — groupés ici, nulle part ailleurs. |
| 15h00–15h15 | Buffer | |
| 15h15–16h30 | **Operations** | Chiffres, décisions, équipe. |
| 16h30–17h00 | Clôture | Review du soir + priorité #1 de demain. |
| **17h00** | **STOP TIME** | Fin du travail. |
| 17h00–20h30 | **Personnel** | Enfants, couple, souper. |
| 20h30–21h00 | Décompression | Sans écran. |
| **21h30** | **COUCHER** | → 7h30 de sommeil. |

**Total deep work : 3h15.**

> ✅ Version principale confirmée par Chris : le gym se fait après le départ du bus.

## Version alternative (entraînement à la maison / gym à moins de 5 min)

- 5h45–6h30 → **Gym**
- 6h30–7h30 → Famille (inchangé)
- 7h45–12h00 → **Deep Work en continu (4h15)**, buffer de 15 min vers 10h00
- Le reste de la journée est inchangé.

Plus puissante (4h de concentration d'un bloc) mais plus fragile : elle ne tient
que si le retour + douche se font sans courir avant 6h30. Règle de décision :
**deux retards au déjeuner dans la semaine → retour à la version principale.**

## Pourquoi le travail à 5h45 et pas le gym

Le bloc 5h45–6h30 a une fin non négociable (les enfants se lèvent à 6h30).

- Un entraînement de 45 min avec trajet + douche laisse ~25 min de travail réel,
  et se termine dans la course. On paie tout l'overhead pour la moitié du gain.
- Un bloc de deep work de 45 min est intact : personne n'est réveillé, aucune
  notification, et il suit directement la lecture — la tête est déjà calme.
- Couper un entraînement à mi-chemin le gâche. Couper une session de travail ne
  la gâche pas : elle reprend à 9h30 exactement où elle s'est arrêtée.

À 7h45 le bus est parti et le gym a de la place pour respirer.

## Règles d'adaptation

- **21h30 est la ligne qui tient tout le reste.** 5h00 sans 21h30 tient trois
  semaines puis s'effondre. Si une seule ligne doit être protégée, c'est celle-là.
- Si le coucher a dépassé 22h30, l'agent allège la journée du lendemain : il coupe
  dans les SHOULD DO, il ne déplace pas le réveil.
- Un call qui tombe dans un bloc Deep Work se déplace vers le bloc Communication.
  Si c'est impossible, c'est le bloc Communication qui rétrécit — pas le Deep Work.
- Le bloc 6h30–7h30 (enfants) et le stop time de 17h00 ne sont jamais entamés pour
  du travail. Un mariage ou une urgence réelle sont les seules exceptions.

## Hypothèses à valider

Ces valeurs sont des estimations — corrige-les et l'agent recalculera les blocs :

- Trajet gym : ~15 min aller-retour → bloc de 1h30
- Retour des enfants de l'école : ~16h00
- Sommeil cible : 7h30
- Pas de mariage en semaine
