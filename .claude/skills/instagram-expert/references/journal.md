# Journal de tests

Un test par entrée. L'hypothèse s'écrit **avant** la publication — une hypothèse
écrite après coup est une justification, pas un apprentissage.

## Format

```
### [DATE] — [Titre court du test]

Niveau visé : attirer | confiance | convertir
Hypothèse : si [changement], alors [métrique] devrait [direction], parce que [mécanisme].
Contenu : [lien ou description]
Ce qui change par rapport au test précédent : [une seule variable]

Résultats à 48 h
- Rétention 3s :
- Watch time moyen :
- % non-abonnés :

Résultats à 7 jours
- Partages :
- Sauvegardes :
- Visites de profil :
- Abonnés gagnés :
- DMs :

Verdict : validée | invalidée | non concluante (volume insuffisant)
Pourquoi, en une phrase :
Prochain test :
```

## Règles

- Une seule variable change par test. Deux variables = aucun apprentissage.
- « Non concluante » est un verdict valide et honnête. L'utiliser souvent est le
  signe qu'on publie trop peu pour apprendre.
- Un test invalidé vaut autant qu'un test validé. Ne pas le supprimer du journal.
- Relire le journal avant chaque plan mensuel. C'est la seule mémoire du compte.
